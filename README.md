# Notes App using Vanilla 
A clean and minimal note-taking web app built with pure HTML, CSS, and JavaScript — no frameworks, no dependencies.

# Tech Stack
HTML — Structure
CSS — Styling with dark/light mode support
JavaScript — Logic & localStorage

# Features
 -Add, edit & delete notes
 -Dark / Light mode toggle
 -Live search across notes
 -Data persists using localStorage
 -Responsive design

# Prerequisites
Just a browser — no installation needed!

# Run Locally
1. Clone the repository:
  bash
   git clone https://github.com/Priti-Mukhi0609/frontend-projects-showcase

2. Navigate into the project directory:
  bash
   cd frontend-projects-showcase

3. Open `index.html` in your browser — done!
